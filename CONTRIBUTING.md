# Contributing

Thanks for helping make this skill better.

## What to contribute

- **Framework recipes** — concrete i18n setups (Next.js, Vite, Vue, Svelte, Expo) that follow the skill's rules.
- **Edge cases** — plural categories, RTL gotchas, locale-routing quirks the current skill misses.
- **Tooling notes** — lint rules for keys, pseudo-localization scripts, missing-key CI checks.
- **Corrections** — if a rule is wrong or outdated (e.g. MessageFormat 2 adoption), say so.

## How

1. Fork the repo and create a branch.
2. Keep `SKILL.md` focused — put deep detail in `references/`.
3. Preserve the frontmatter `name` and the "Use when..." style description (that's how agents discover it).
4. Run any checks, then open a PR describing what changed and why.

## Ground rules

- Be respectful and constructive.
- No hardcoded strings in your own examples — practice what the skill preaches.
- Keep examples framework-agnostic where possible, and label framework-specific ones clearly.
